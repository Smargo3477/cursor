# 我的记事本

这是一个适合新手练习的纯前端记事本程序，不需要安装依赖，直接用浏览器就能运行。

## 功能

- 新建、编辑、删除笔记
- 按标题或内容搜索笔记
- 自动保存到浏览器本地存储
- 适配电脑和手机屏幕

## 运行方式

最简单的方式：解压下载包后，直接双击 `index.html`。

`index.html` 已经内置样式和功能代码，所以只打开这一个文件也能看到完整界面。

如果你想用本地静态服务器，也可以在项目目录运行：

```bash
python3 -m http.server 8000
```

然后打开：

```text
http://localhost:8000
```
